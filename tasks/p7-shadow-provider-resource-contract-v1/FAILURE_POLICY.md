# Approved shadow-only failure boundary

Unavailable provider, load failure, timeout, GPU OOM, system RAM pressure, watchdog/GSP failure or crash must leave legacy processing unchanged. No authentic adapter response means no authentic zero-proposal result (D05 ZERO_PROPOSAL.md). Record unavailable/incomplete through a separately defined evaluator/accounting boundary; do not invent P7 enum members or manufacture terminal pipeline observations.

No fallback provider, tools, dispatch, safety disable or new restart automation. Existing systemd Restart=always/RestartSec=3 is observed configuration, not a new recommendation. Do not modify it. Storage failure must remain separate from model failure and must invalidate measurement according to D04.
