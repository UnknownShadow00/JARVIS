# Security defenses

| Threat | Frozen defense | Limit / follow-up |
|---|---|---|
| model success promoted to execution truth | no execution/success fields or result input; reject inert tool-success/error labels | trusted execution version is out of scope |
| model tool promoted to authority | binding fields copied only from existing JARVIS binder; proposal facts are count/guard observation | origin must be established by future evaluator |
| client fake identifiers | no client deserialization path; P1 owner association/type/shape and terminal equality | type/UUID shape alone is not authentication |
| trace confusion | retain separate observational trace; never mint/derive turn from it | absent trace is None |
| cross-session association | one authoritative correlation, terminal match, evaluator associates ID-less owner facts to it | no guessing owner provenance |
| mutable P2 leakage | no ledger/store/snapshot input or output | existing P2 owner remains separate |
| secret/request leakage | raw text/targets/maps/exception prose excluded; narrow canonical fingerprint only | digests remain linkable/dictionary-guessable; D04 privacy controls pending |
| audit truth contamination | no audit-v3 type/serializer/writer or claimed operation | F-AUDIT-01 remains open |
| provenance contamination | observation never enters P2; no new source/trust class | no model/shadow promotion |
| hidden registry access | only settled binder data; no registry or snapshot call | imports/call graph checked in future tests |
| hidden dispatcher/executor | no handles/results/callables/dispatch import | runtime sentinel proof later |
| clock nondeterminism | no time input/source/output or clock call | D04 timing remains open |
| persistence side effects | returns immutable data; no write/callback/queue | future sink is separate |
| duplicate observations | one returned value per valid terminal invocation; no global attempt identity/dedup claims | D02/D04/D07 retry/loss/cardinality decisions preserved |
| contradictory settled facts | exact validation; reject rather than repair/re-evaluate | no majority merge or inferred success |

Permission, confirmation, browser D-01 and audit schemas remain unchanged. Candidate source/lane/obligation labels are not user-visible delivery, external mutation or trusted operational provenance. No imported helper may hide evaluation, discovery, clock or I/O.
