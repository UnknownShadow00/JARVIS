# Terminal boundary and scope

V1 observes an initial inert-shadow evaluation reaching an actual existing P7 terminal return: PipelineStop, ApprovedOperationalResponse, or ConversationalResponse. The evaluator supplies its existing AdmissionMode.INITIAL_TURN as settled scope metadata; no confirmation continuation or result replay is admitted into this inert V1 record. This restriction is producer scope only; existing RecordedTurn alternatives remain unchanged.

Every record has authoritative correlation. Context/envelope failure before settled association, BindingProjectionError with no P7 terminal return, unavailable live adapter/provider, raised API misuse without PipelineStop, and producer failure are outside V1 terminal records. Do not translate these into new terminal enum values or forge S01_INPUT/ADAPTER_INVALID. An actual parser failure that returned PipelineStop(S05_ADAPTER, ADAPTER_INVALID) is supported exactly. A valid empty binding followed by a real unsupported/P7 terminal is supported.

One producer invocation for one admitted terminal attempt returns one record, or fails closed and returns none. The future evaluator should invoke it once per terminal evaluation attempt, not per stage, stream chunk or fallback. Stateless repeat projection of identical facts returns an identical record; it neither creates nor identifies a new evaluation attempt. No global once-per-turn guarantee or exactly-once sink delivery is claimed. Whether retries are new attempts/turns, and how duplicates/loss are accounted for, remains D02/D04/D07. No attempt ID is invented. A sink cannot safely deduplicate all records by turn ID alone before those decisions.
