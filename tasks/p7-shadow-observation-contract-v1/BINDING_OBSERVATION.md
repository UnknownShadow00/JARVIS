# Closed binding observation

Canonical BindingProjectionV1 has five frozen fields; expected and permission_projection are both present or both None. `_ROWS` currently admits only OPEN_APP → apps.open → apps and OPEN_URL → browser.open → browser. The observation producer does not derive these pairs, read the row table/registry, call binder/canonicalizer or select an action/tool/capability.

It copies binding.metadata_digest; for a present pair, it copies query.primary_action, query.capability and expected.tool_name, then fingerprints expected tool/version/full canonical arguments. The four admitted-binding fields have all-present/all-None shape. Existing binder schema version must be exactly "1". A one-sided pair or nonimmutable canonical map is inconsistent input and rejects. If an actual route is also supplied, its primary_action must agree with the already-settled binding query; checking the same fact for contradiction does not derive a mapping. Do not manufacture a present pair from RouteResult or a ToolProposal.

Downstream evidence compares the observed copied triples and fingerprints against the separately frozen V1 rows/references; an accidental third tuple is visible to that check. The producer neither authorizes a third mapping nor implements a competing crosswalk. Existing binding ownership/authenticity is required; a hand-built class with arbitrary names is not a genuine binder output merely because its shape passes. Future collection/source-version proof remains evaluator/evidence responsibility.

For a legitimate non-admitted/unsupported binding, metadata digest remains present, admitted-binding fields are None, and primary_action/terminal outcome come only from actual settled P3/P7 facts. If no binding was supplied, all binding fields including metadata digest are None. Missing observation is not capability absence. An exact binding fingerprint distinguishes canonical targets without storing target text, and proposal_match remains the actual upstream full guard result, not equality recomputed here.
