# ShadowObservationRecordV1 — frozen schema

A frozen, slotted, data-only value with exactly the 18 fields in FIELD_INVENTORY.md / FIELD_INVENTORY.json. Reuse existing CorrelationContext, PipelineStage, PipelineStopReason, Lane, PrimaryAction, PermissionOutcome, ResponseObligation and response-source enums. outcome_type is a literal projection of the three existing Python return-type names, not a new terminal-state enum. No measurement identity or separate session/turn/correlation scalars.

For PipelineStop: stop_stage/reason are present; candidate_obligation/source are None. Lane/action/permission may be available through its actual obligation_state or separately settled route/permission input; no obligation is derived from the state. For response alternatives: stop_stage/reason are None. ApprovedOperationalResponse carries its existing lane/obligation/source; ConversationalResponse carries its existing conversational lane/source and has no obligation. Presence/status of a candidate is completely determined by outcome_type, so no redundant candidate_present/approved/success field is stored.

Binding presence is explicit through binding_metadata_digest: None means no binding observation. A valid binder output with expected/query both None retains its metadata digest and has all four admitted-binding fields None. A present pair copies action/capability/tool and hashes its canonical content. No raw target/maps are retained. An unmatched proposal cannot overwrite the deterministic binding fields.

Null proposal_count is unobserved, distinct from observed zero. Null proposal_match is unobserved/not compared, distinct from observed False. Null permission_outcome is unavailable, never DENY or ALLOW. These nullable observations are required constructor fields. V1 does not invent more states to conflate these with adapter absence or success.

Excluded: executed/success/confirmation-claimed/visible-replacement flags, tool result/provenance payloads, counters asserting execution absence, raw user/model/candidate text, clocks/times/durations, attempt IDs, guard prose, component exception text, request/snapshot/store/framework references, registry/provider/dispatch objects, loss/retention/persistence settings. No public wire serializer, sink format or aggregation threshold is frozen. The record itself cannot certify zero runtime calls, complete traffic coverage, CT pass or delivery.
