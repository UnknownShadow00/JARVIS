# Stop, drain and terminal truth

Nonproduction Gate 6E reference implementation. No production installation, experiment approval, model traffic, credential use or measurement. G6D-LP-1 remains a proposal.

Stop latches admissions closed. Accepted capacity is never refunded. A stop before send may leave a conservative possible-send record if ordering was interrupted. During classifier/responder/Granite work, cancellation retains remote unknown in controller, D06 and domain ledger. Local task cancellation is not remote terminal proof.

Delivery completion callbacks retain a legacy ASGI send fact even if stop/timeout arrives concurrently. Missing delivery persistence closes recovery; generated-only text never becomes delivered history. Receipt-append uncertainty and checkpoint faults prevent another permit. Stop during checkpoint cannot overwrite terminal state with CHECKPOINT_HOLD.

Drain bounds local asynchronous waiting to at most the frozen30s parameter. Once tracked tasks retire it creates a final coordinated checkpoint, READY or FORENSIC_INCOMPLETE as evidence allows. CAP_COMPLETE also writes a terminal checkpoint. Final checkpoint failure durably downgrades CLOSED_COMPLETE to CLOSED_INCOMPLETE in controller and high-water root. No terminal state reopens. The human socket stop latches synchronously; an isolated supervisor must subsequently invoke drain. There is no installed supervisor/helper.

Tests include zero-use stop, blocked router/Granite, delivered response then uncertainty, receipt persistence faults, checkpoint stop/fault, accepted reservation crash, final unknown forensic snapshot and final failure downgrade. Synchronous filesystem stalls and real process-supervisor shutdown ordering remain unqualified; the30s local bound is not a host-wide remote-completion guarantee.
