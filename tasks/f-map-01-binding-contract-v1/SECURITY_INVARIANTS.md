# Security invariants

- JARVIS classifier, router, canonicalizer, registry metadata and P4 policy own deterministic authority; a model only proposes.
- No raw user text, client flag, UI/API field or model value directly authors route, capability, tool, canonical args, permission, confirmation or result.
- No model operational prose is exposed by the binding projection; P7 response composition remains authoritative.
- The binder imports no confirmation machine/store, dispatcher, executor, registry execution API or provider client. It cannot create `TrustedToolResult`.
- Projection creation is pure: zero network, subprocess, model/Ollama, `registry.call`, dispatch, real tool, confirmation/provenance/audit mutation, clock-dependent choice or random choice.
- Result replay remains a non-execution continuation. Existing origin-authenticity and replay follow-ups remain open.
- No live registry/consumer, no policy or audit schema mutation; execution mode stays `legacy`, Hermes disabled.
