# Trace versus correlation

Carry the Context V1 observational trace association unchanged. Do not read a later trace after the context has ended, compare trace to turn for equality, derive IDs from it or treat None as a reason to manufacture identity. Required correlation remains the canonical P1 context. REST and WS get the same semantics regardless of trace formatting. The older P1 trace-reuse docstring is superseded for this contract by operator A8, not edited.
