# Artifact link handling

An initial seal guard refused pytest temporary-directory aliases retained inside
run outputs. No manifest had been published and no evidence was deleted or
rewritten. The final seal inventories link targets in SYMLINKS.json without
following them; regular files are separately hash-bound. The verifier compares
both inventories exactly. The source archive and all mounted input files remain
symlink-free. Absolute /work links describe the original isolated test cage and
are evidence observations, not host paths to open.
