# Fail closed without affecting legacy

If authoritative session, turn, snapshot, association or exact string request is missing/invalid, future composer produces no envelope. It must not synthesize a session, empty ledger or P7 input to keep shadow running. Shadow capture failure must not raise into REST/WS legacy processing, change the reply/stream, call a model or execute fallback tools. An approved future measurement path may record a bounded diagnostic; audit representation remains deferred. No runtime code is introduced here.
