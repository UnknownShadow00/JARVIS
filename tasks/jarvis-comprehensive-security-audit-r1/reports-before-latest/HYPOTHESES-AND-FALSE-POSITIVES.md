## B — Filesystem ancestor replacement

Application helpers use absolute paths, symlink checks and leaf no-follow/type/UID/mode/link controls. They do not pin every ancestor with descriptor-relative operations or validate each ancestor's ownership/write permissions. A different OS principal must first have relevant ancestor replacement authority. Same-UID process/key control is trusted by the documented contract.

The minimum deterministic fixture swapped a same-UID ancestor only at the final writable SQLite connection and restored the expected pathname before subsequent fences. SQLite rejected construction with `OperationalError: attempt to write a readonly database`; no fabricated task was accepted. This exact chain was repeated against the later current capture with the same result. See agents/hunt-ledger/artifacts/ancestor_connection.txt and agents/parent-current/artifacts/ancestor-current.txt. This disproves that tested chain; it does not prove every possible ancestor race is impossible.

Repository-ancestor metadata was observed without opening state or credentials: `/` and `/opt` were root-owned 755; `/opt/apps` was UID 1000-owned 755; the workspace/projects/JARVIS ancestors were UID 1000-owned 750, without group/world write mode bits. Actual configured checkpoint/archive/custody ancestors, ACLs, mount/sticky controls and a rename-capable different UID were not inspected. No cross-UID qualification was performed. The broader deployed claim remains unqualified and has no severity.

Current broker successor securefs uses directory-relative no-follow traversal and owner/write-mode checks on every component; its positive fixture evidence cannot be transplanted to the application's absolute-path helpers. Suggested application hardening: require trusted non-writable ancestors, retain verified directory descriptors for supported leaf operations and authenticate/fence the actual SQLite connection before takeover. SQLite's path/WAL semantics require deliberate handling; a generic file no-follow flag is not an ancestor guarantee.
