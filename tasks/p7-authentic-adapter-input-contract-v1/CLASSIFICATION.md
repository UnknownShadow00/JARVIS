# Conceptual origin/parse/eligibility classifications

No canonical adapter/pipeline origin enum exists. Freeze semantic descriptions only, not a new production enum or caller-settable trust flag. The trusted future transport/evaluator/controller owns classification from observed origin, not the sink or a model claim.

| Description | Required basis | Measurement limit |
|---|---|---|
| Live authentic adapter input | Real same-turn provider operation, faithful canonical input and actual successful sole-parser use | May contribute to formal live model-proposal measurement only after D06/D07/controller/runtime requirements; no pass implied |
| Replay authentic adapter input | Demonstrated previously captured provider origin, original association/seal, explicit replay and successful canonical reparse | Replay/regression evidence only, never fresh live |
| Synthetic test input | Handbuilt recordings/objects/mocks, regardless of parse/seal or replay operation | Tests only; canonical parsing cannot launder origin |
| Unavailable input | No completed provider response/valid input available, including timeout/cancellation | Explicit failed/unknown attempt accounting; never zero proposal |
| Invalid or unverified input | Malformed canonical data, contradictory association, unknown origin or incomplete authenticity evidence | No authentic successful adapter result/eligibility claim; preserve truthful failure/unverified facts |

Provider origin and parser applicability are separate facts. A real provider return can be known while P7 stops before S05; parse is then unobserved, not a fabricated invalid/unavailable provider or empty set. Do not force a successful-origin category onto an absent parse result. Existing D03 nullable count/match represents that absence of observation. A malformed response may be genuinely live-origin yet yield no valid adapter output. Counts/threshold/denominator treatment belong to D09, with failed/unobserved attempts retained by D02/D07.

A label alone does not prove origin. Hash/date/type equality cannot distinguish a perfect fixture from a real return. The future controlled capture/normalization/parser-use evidence and reconciled association are required; if missing, no measured-live contribution can be claimed.
