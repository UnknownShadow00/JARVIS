# Exact fixture encoding and scope

These JSON files are static test construction recipes, not an admission transport, implementation or pipeline result. Each whole_turn case explicitly carries all 21 RecordedTurn fields. Construct the named existing types from the field table; for confirmation use only the future SettledConfirmationProjection. Enum strings mean exactly the corresponding enum values. ISO strings mean datetime.fromisoformat, aware except the explicitly malformed fixture. Lists in tuple/frozenset fields become that declared immutable container. `NO_VALUE` means the existing obligations.NO_VALUE. Nested mapping/sequence data must be recursively privately copied/frozen before admission. Preserve scalar types (bool/int/float differ). No raw model/provider data is converted to invocation/result or projection: these are separate, explicitly test-owned static inputs, with no authentic-dispatch-origin claim.

`recording` is an exact string, parsed only by the frozen adapter. `proposal_ids` is an ordered tuple. Build AdapterRequest with exact tuple messages and ToolSchema instances; empty schema advertisements are intentional in N47. CanonicalizationResult fields are literal caller expectations; P7 still calls actual canonicalize for the candidate. Snapshot construction uses exact session and records, with named ProvenanceRecord enums/times. Optional None is actual None, never an invented default. Existing constructors may need the pre-frozen nested containers; fixture loading is a test helper, never a production coercion path.

Controls are outside RecordedTurn. `extra_constructor_fields` tests closed constructor rejection before call. Runtime type overrides deliberately pass a mapping, namespace, ModelDraft, ToolProposal or trivial subclass in place of a discriminator; the fields remain otherwise unchanged and S01 rejects exact identity. A ConfirmationRecord-look-alike is an ordinary test-owned attribute object, never an import or lifecycle instance. Naive expires_at is an exact projection with malformed member, rejected at S08. Invalid audit ID is invalid under existing P1 vocabulary.

Fault injection replaces only the named owner call/output within the future test. The declared exception is the existing owner error with test text 'fixture failure'; arbitrary text never becomes component_reason. N14 replaces parsed proposal_id with its fixed alternate identifier to exercise defense after adapter parsing. These are explicitly owner_fault_injection, not claims that the unchanged parser or policy normally creates that state. Never override a policy outcome to force a successful whole-turn path. No dependency parameter is added to P7.

Component-boundary cases freeze exact P6 states or internal audit candidates. They do not call run_recorded_turn, skip its guards or enlarge its public API. C14's existing premise is a denied/executed state already reaching the obligation engine; N31 uses a real standalone P4 denied capability plus an explicit P6 state. Today's two routed/mapped capabilities do not imply a whole-turn DENY path. This is the component separation already frozen by O-R1, with matrix row objects unchanged. N26/N27 test internal audit applicability through a private-boundary test or invalid-candidate injection, never live event emission. PB02-immutable separately tests frozen construction, deep alias isolation and rejection of callable/arbitrary objects; no lifecycle stand-in is admitted.

Expected stage is the stopping stage for PipelineStop; successful outcomes end at S13_AUDIT. `branch_stage` records an earlier terminal handoff (e.g. historical A02/B01 matrix last_stage S08), not a contradictory final return stage. Guard strings identify frozen predicates for test traceability; they are not new public guard enums or fields. For a stop, correlation is always the identical admitted turn.correlation; result/state identity references are exact assertions, not strings placed in the production stop. A retained downstream state must contain the identical result; before S09 all result/state references in stops are None as declared. P6 contradiction failures retain the diagnostic state specified by the component or actual composition.

Expected downstream_output specifies all response fields plus separate diagnostic obligation reason/template; compare only real fields to the returned dataclass, and diagnostics to the actual owner decision. No new fields are added to any production output. The expected-obligation-state entry records the isolated owner's complete fixture state. All global effect counts are zero per evaluation, including repeated evaluation. Source snapshots and component observations are supporting evidence, not a scored pipeline test.

The original six O-R1 contradiction recipes are retained byte-for-byte in contradiction-corpus-v1.json; concrete fixtures are mapped by CONTRA-C01–C06. Forty-seven N rows and all thirty-two admission rows have explicit coverage. Structural cases verify exact P-B04 authorizations after implementation and immutable historical absence hashes; they have no runtime stage or downstream response.
