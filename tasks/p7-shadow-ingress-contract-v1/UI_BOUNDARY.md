# UI path

PWA, Electron and hologram clients use existing REST/WS server surfaces (`CURRENT_INGRESS.md`). Formal P7 UI coverage means those normal requests traverse the shared shadow observation path while the same visible legacy reply remains. No indicator, redesign, extra UI field or client flag is required by the phase graph. WS stream bypass must be resolved; otherwise the UI criterion is unproven. No shadow text is sent to UI/TTS/broadcast.
