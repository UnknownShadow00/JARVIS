# Recorded Corpus — Not Frozen

The required corpus was not frozen because there is no canonical raw input schema against which
to author valid, malformed, extra-field, duplicate-field or multiple-proposal cases.

Historical C5 evidence was inspected read-only. It includes separate raw draft text and normalized
Hermes-agent structured calls, for example:

```json
{"arguments":"{}","id":"call_ziaq1eok","name":"jarvis_test_get_database_status"}
```

That is evidence of a prior harness representation, not a frozen P7 production adapter contract.
Freezing a corpus around it would silently decide the ambiguity after seeing one provider shape.
