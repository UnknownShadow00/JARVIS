# Reasoning fields
The main contract freezes the normalized P1 forbidden-key family plus reasoning/thinking, recursively across the canonical recorded payload. Tests use only synthetic sentinel values, never actual private reasoning.
A v1 transport envelope does not exist, so there is no ignored envelope branch.
No raw document is returned, audited or persisted; errors expose fixed codes and no chained decoder input.
Normal assistant text is permitted only as untrusted ModelDraft.text. Semantic detection of disguised reasoning in prose is not claimed. The future provider normalizer must separate actual reasoning from final assistant content before this boundary.
