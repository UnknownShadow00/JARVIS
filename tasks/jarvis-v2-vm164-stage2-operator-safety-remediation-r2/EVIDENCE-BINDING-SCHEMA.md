# Evidence contract

The executable consistency contract is `src/results.py`, with strict wire checks in `binding.py`, command/time checks in `packet.py`, collision proof in `collision.py`, and bounded file loading in `artifacts.py`. `RESULT-SCHEMA.json` lists mandatory structural fields; algorithmic timing, raw serialization and cross-artifact checks remain mandatory in addition to JSON Schema. Duplicate JSON keys, malformed/truncated/oversized data and nonfinite numbers fail.

Top-level bindings: R2 source hash, independently pinned packet-manifest hash, R3 source tree, exact callback hash, session/authorization/operator/distinct reviewer, identity/privilege/environment review hashes, approved start/end UTC and BOOTTIME anchor, clock-domain basis digest, final closure sample, failure list, exactly twelve case records, evidence manifest and externally retained manifest seal. `expiration_guaranteed` and `live_qualification` must remain false. A synthetically labeled result returns PASS_SYNTHETIC_ONLY; captured results can return only PASS_CONSISTENCY_ONLY. Neither grants authority or authenticates origin.

Each case binds its exact name, timer and service, generation digest, source pins, numeric UID, fresh initial sample and raw collision proof, consumed-name custody, original absolute deadline and executed argv/hash. A plan binding digest covers all plan fields other than its kind/digest. `check_plan` reconstructs expected argv including the ExecCondition public binding; changing a field and rehashing does not make a different executable acceptable.

Required observations include two complete waiting captures (zero for the explicitly failedtimer probe), final raw timer/service properties, decoded values identical to those raw bytes, and clock/show capture receipts. Each receipt binds exact argv/hash, actual stdout/stderr, numeric exit, elapsed duration, no timeout/overflow/signal and a fresh finite sample. Clock arithmetic and the boot/UTC/BOOTTIME relationship must agree. Missing User/Group/security/environment/reset/timeout/resource/ExecStart/ExecCondition/job/exit properties fail. UNKNOWN serialization is not normalized by guesswork.

Each case carries raw journal JSON-lines, an exact journal command receipt, selected events derived again from those bytes, and contiguous creation-to-final-capture coverage metadata. Trusted journal unit, boot, numeric UID, cursor and InvocationID bind guard and payload. The guard binds generation/window/source and verifies runtime credentials/environment without logging arbitrary values. Callback boot/UID/eUID/both clocks/mode/non-VM/root-bootstrap-false and manager waitid code/status/result must match the case. Timeout requires its probe; import/exec failures require diagnostics. Duplicate cursors/invocations and missing callback evidence fail.

Cancellation records require no execution, the original pre-deadline stop time, no trigger/invocation and complete final inactivity/cgroup proof. Rearm-a must remain unexecuted through rearm-b's closure. Receipt order must include exact timer then service stops for final reviewed results, preserving interrupted checkpoints; repeated helper cleanup on a proved terminal pair is a no-op. Failure lists must be empty only for complete reviewed observations, and an earlier failure cannot be superseded by a new generation. Incomplete/failure archives are retained as such, not fed to the reviewed-success validator.

Exactly twelve `cases/<case>.json` files are canonical JSON (UTF-8, sorted keys, compact separators) of the complete case objects, including raw data. Their hashes and byte sizes form the evidence manifest; the external seal is SHA256 of canonical manifest JSON. Actual bytes are loaded with no-follow, type/ownership/size/time checks. `results.validate` requires actual artifact bytes plus **both** independently retained expected evidence-manifest and packet-manifest hashes. Top-level summaries cannot replace files. Tampered bytes or resealing against an unchanged external pin fails. The operator must independently preserve the original external seals and append-only custody ledger; a party who can rewrite evidence and every trusted seal can fabricate provenance, which these hashes do not prevent.

Review invocation (an offline Python API call, not a host executor):

`results.validate(record, artifacts.load(evidence_root, record['evidence_manifest']), expected_manifest_sha256=independent_evidence_seal, expected_packet_manifest_sha256=independent_packet_seal)`

Local evidence root ancestry is an explicit trusted-workstation precondition; children and root leaf cannot be symlinks. Do not place credentials or inherited environments in artifacts. Machine-readable SYNTHETIC-12-CASE and SYNTHETIC-VALIDATION files demonstrate structure only; their dates, UID claims, hashes used as review stand-ins and observations are invented fixtures, clearly labeled and never actual host evidence.
